# Where community builds come from

- **PvX wiki** (<https://gwpvx.fandom.com/>) — build names, professions, skill bars,
  attributes, ratings and tags, each entry linking to its PvX page. PvX content is
  licensed CC BY-NC-SA 2.5; only these facts are used and no prose is copied. The
  dataset is read from gw1tools/gw1builds (MIT).
- **Reddit / YouTube** — found by the weekly crawl; the poster's own words are quoted
  and linked to the original.
- **Imported files** — whatever list is handed to `npm run community`.
